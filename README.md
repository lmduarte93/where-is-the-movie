# Where is the movie

Busca em qual streaming do catálogo brasileiro um filme ou série está.
Dados: TMDB + JustWatch (região BR).

## Publicar na Vercel
1. Suba esta pasta num repositório do GitHub.
2. Na Vercel: Add New → Project → importe o repositório.
3. Em Environment Variables, crie `TMDB_TOKEN` com o token de leitura (v4) do TMDB.
4. Deploy.

Link de busca direta: `https://seu-site.vercel.app/?q=Duna`
